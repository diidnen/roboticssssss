# V4 method contract

V3 R2 is immutable negative engineering evidence. Its parity comparison was defective: it did not capture all mutable Python robot/interpolator/recent-buffer state and compared disabled executions rather than untouched versus disabled.

V4 decisive tests reconstruct one branch in one fresh interpreter. The same V2 executed prefix, fixed init/seed/friction and nominal bytes are replayed to each preregistered step. Each child writes an atomic receipt and exits. `untouched` installs no adapter; `disabled` installs it with zero force and false enable. State/action/controller/contact evidence is compared across independent children.

The adapter is local to the child controller instance. Stock OSC first produces its torque, then the adapter adds `J_pos.T @ F_world`; stock SingleArm clipping remains next. Requested units are hypotheses until signed measured contact response passes.
