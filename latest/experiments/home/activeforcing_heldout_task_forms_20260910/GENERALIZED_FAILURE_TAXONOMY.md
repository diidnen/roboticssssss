# Generalized failure taxonomy

Apply to valid downstream execution after the established grasp. A category requires supporting telemetry or frames, not a presumed lift phase. Preserve secondary flags when several mechanisms occur; mark an uncertain primary cause OTHER rather than inventing causality.

| Primary category | Required evidence | Examples of task-specific subcategories |
|---|---|---|
| GRASP_RETENTION_FAILURE | Loss of bilateral support or object-hand displacement before intended release, affecting completion | extraction slip; rotational slip; vertical-load drop; grasped-drag slip |
| TASK_CONTACT_FAILURE | Maintained grasp but task contact prevents progress | insertion jam; collision with rim; drawer resistance; dragging snag |
| VLA_EXECUTION_FAILURE | Online policy follows wrong semantic target or fails the required motion while the physical state permits it | wrong receptacle; never executes extraction; wrong wrist motion |
| TERMINAL_GEOMETRIC_FAILURE | Valid execution ends outside frozen pose/containment/alignment criterion | partial insertion; wrong compartment; orientation error; extraction incomplete |
| RELEASE_FAILURE | Required VLA-controlled release does not produce the frozen terminal unheld state | no open intent; retained object after open request |
| OTHER | Valid failure with insufficient evidence for another category | ambiguous execution/contact interaction |

Use an additional infrastructure/interface status outside the physical failure taxonomy. Pregrasp VLA failures in native-reset qualification are also recorded separately: they cannot establish downstream AF failure, force insufficiency, or incompetence from an already supplied grasp.

The key physical diagnostic is whether selected force maintained the grasp under the task-relevant load. Native goal failure alone cannot answer it. Fixed-5 task selection must not read any AF outcome. Regrasp after release is a scope violation for this experiment and is reported explicitly, never silently recoded as single-grasp success.
