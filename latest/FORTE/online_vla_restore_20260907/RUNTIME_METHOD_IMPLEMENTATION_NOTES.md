This is an implementation-grounded method note for the final paper package. The four-root main evaluation is running under the frozen final manifest; final aggregate success rates remain pending. Current-server development qualification passed before the first fresh-root branch. The attached September 2 manuscript remains unchanged.

ActiveForcing adapts grip force starting from a common established-grasp state. It does not plan the initial grasp. Every main method executes the same physical probe and reconstructs the same post-probe state. The existing 58-dimensional physical-evidence encoder supplies a continuous posterior over the modeled physical parameter. The current evaluation varies friction within the four authored object-to-basket tasks; it does not establish mass adaptation or damage prevention.

Before executing any downstream action, the frozen pretrained Tabero pi0 policy receives the current observation and the historical task instruction, and predicts its first native action chunk. Feasibility uses the first eight predicted Cartesian positions and their increments together with the current measured state, observation masks, task identity, posterior hypothesis, and candidate force. Thus the sequence is an online prediction available at the decision state, not an observed future trajectory. Subsequent arm actions continue to come from new native policy queries during the rollout.

The final candidate feasibility input has 64 channels: 10 sequence channels (six chunk-kinematic channels and four task indicators) and 54 condition channels (candidate force, physical hypothesis, and duplicated 13-dimensional measured-state/mask blocks). This is separate from the 58-dimensional probe-evidence vector. All seven legacy scripted phase channels were normalized constants on the original 647 matched rows. Their exact weight-column removal preserves all original predictions and force decisions without fitting new parameters. No phase proxy or hidden scripted stage is used. The six motion channels now come from the current VLA prediction; their near-constant values in the old training set do not support a claim that diverse VLA motion dependence was learned.

The feasibility ensemble was trained on controlled-motion full-task labels. These labels remain explicitly scripted auxiliary supervision. Transfer to the online frozen VLA is assessed on burned development roots before the final runtime freeze. The selected phase-free derivative has no new optimizer steps and uses no VLA-matched retraining data. The separate offline phase-removal retraining experiment is a sensitivity comparison, not the selected final estimator.

For each candidate force, predicted success is marginalized over the continuous posterior using the existing positive quadrature. The implemented utility is `p_success(F) * (5 - F) / 5 - (1 - p_success(F))`. The continuous-force model is optimized numerically on the frozen 0.05 N grid over [3, 5] N, with the lower-force tie break. The implementation selects F once after the probe; it does not re-estimate the posterior or reselect F at every VLA query. The force controller then provides continuous feedback during downstream execution.

The VLA predicts 50 actions per query; the runtime executes 10 and then requeries from the live observation, at a nominal simulated control interval of 0.05 seconds. The decoded six-dimensional arm action passes through unchanged. ActiveForcing owns the squeeze-force reference and its existing gripper servo. The raw VLA squeeze dimensions are logged and masked; native near-full-opening intent remains effective through the common release rule. Fixed-3, Fixed-4, Fixed-5, and AF use the same arbitration and physical controller; only the selected force strategy differs. No downstream waypoint prefix or cached action trajectory is executed.

The native model returns 50-by-32 raw samples, and its unchanged decoder returns 50-by-13 executable commands: six arm coordinates, one absolute per-finger position command, and two three-dimensional force vectors. During squeeze control, AF supplies F/2 to each normal-force component and zero tangential references. The raw per-finger opening command is interpreted as release intent only near the canonical fully open position; it is not a binary gripper score or the measured total aperture.

Each rollout binds observations, raw and decoded chunks, request/worker/context identifiers, sampling seeds, hashes, inference timestamps, selected and realized force, and executed actions. Noise seeds are matched across methods on shared native query steps. Cross-process bitwise action reproducibility is not claimed: a server restart produced small numerical differences under identical inputs/noise. The source discrepancy was recovered exactly as an equivalent project-root path assignment; model weights and native inference functions were unchanged. The replacement instance passed complete 36-branch development qualification under the original acceptance thresholds and is pinned for the final main evaluation. One changed development outcome was retained and disclosed; qualification did not require every old outcome to repeat.

The final paper must distinguish observed simulator state from a demonstrated real-robot perception pathway, and simulated inference cadence from hardware hard-real-time execution. Full-task success uses the frozen whole-mesh placement/release/support contract. Measured bilateral squeeze is `2 * min(left_normal_force, right_normal_force)`, with both nonrelease and contact-conditional summaries. Force saving is based on selected setpoints, so post-drop zero-contact samples cannot create artificial saving. The independent statistical groups are four fresh simulator reset roots, not 192 independent branches or individual timesteps.

`PRIOR / NO-POSTERIOR` retains the physical probe and changes only the posterior used for force selection. It must not be called `NoProbe`. Proposed uncertainty-driven re-querying and sampled-force optimization from the attached manuscript are not established by the current implementation. Scripted V5 tables and ablations remain controlled-motion development evidence and cannot enter online-VLA main or ablation tables.
