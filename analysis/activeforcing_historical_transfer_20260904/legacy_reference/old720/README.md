# old720 inventory and reference

The old720 archive was found and transferred because it is small enough for a normal GitHub commit: 720 branch rows, 446,539 bytes in the core CSV, 4 tasks, 72 friction-conditioned contexts, and 24 root families.

It is later GNP-style continuous force data, not the old AFI `FRICTION_GRU.pt` posterior chain. The audit reports strict compatibility limitations and must be read before reuse. No old720 checkpoint is included in this bundle.
